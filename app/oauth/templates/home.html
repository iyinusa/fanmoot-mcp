{# ── Connect ───────────────────────────────────────────────────────── #}

Sixty seconds

One URL. Every client.

Each client registers itself the first time it needs a fan, then sends you through a Fanmoot sign-in — or sign-up — right here.

01Claude Code 
claude mcp add --transport http fanmoot {{ mcp_url }}
02Claude — desktop and web

Settings → Connectors → Add custom connector, and paste the server URL. For a desktop app that only runs local servers, bridge it in claude_desktop_config.json:

{ "mcpServers": { "fanmoot": { "command": "npx", "args": ["-y", "mcp-remote", "{{ mcp_url }}"] } } }
03ChatGPT

With developer mode on (Settings → Apps & Connectors → Advanced), create a connector with the server URL and OAuth authentication. ChatGPT registers itself and finds the sign-in from the server's challenge.

04Cursor

~/.cursor/mcp.json, or .cursor/mcp.json in a project:

{ "mcpServers": { "fanmoot": { "url": "{{ mcp_url }}" } } }
05VS Code

.vscode/mcp.json:

{ "servers": { "fanmoot": { "type": "http", "url": "{{ mcp_url }}" } } }
06MCP Inspector 
npx @modelcontextprotocol/inspector --transport http --server-url {{ mcp_url }}
07Any stdio-only client

mcp-remote turns this server into a local stdio one, OAuth included:

npx -y mcp-remote {{ mcp_url }}

For developers

Built to the spec. Safe by default.

An MCP server with its own OAuth 2.1 authorization server. What a client holds is never a Fanmoot token — it is a revocable handle that expires in {{ access_hours }} hour{{ "s" if access_hours != 1 }} and means nothing to fanmoot.com.

Discovery

  • /.well-known/oauth-protected-resourceRFC 9728
  • /.well-known/oauth-authorization-serverRFC 8414
  • /.well-known/openid-configurationOIDC

Public by design: a client reads these before it holds any token. They list endpoints and capabilities — never a key, a secret or a fan's data.

  • Authorization code + PKCE, S256 only
  • Rotating refresh tokens, stored as hashes
  • Self-registration: RFC 7591 and client metadata documents
  • Origin checked on every /mcp request
